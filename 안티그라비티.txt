지금까지 만든 여러 바이브코딩 앱을 소개하고, 개인정보처리방침을 게시하는 랜딩 페이지를 만들거야.
모던하고 깔끔한 디자인, 인디고 계열 색상, 모바일 반응형으로 만들어줘. 아래의 [기술 스택]과 [지시 사항]을 참고해줘.
디자인은 첨부한 스티치(Stitch) 기반의 UI 컴포넌트 코드(React + Tailwind CSS + Lucide Icons)를 바탕으로 바인딩해 줘.
랜딩페이지에 사용되는 문구는 한 곳에서 쉽게 고칠 수 있도록 하나의 파일에서 변수들로 정의해줘.

[기술 스택]
Next.js (App Router), React, TypeScript, Tailwind CSS
인증/DB: NextAuth.js (Google OAuth), Dexie.js (로컬 IndexedDB)
유틸리티: framer-motion (카드 애니메이션용, 필요시 추가)

[지시 사항]
기존에 스티치로 작업된 UI 컴포넌트 구조를 먼저 파악하고, 컴포넌트 설계 접근법을 짧게 브리핑해 줘. 내 승인이 떨어지면 순서대로 코드 작성을 시작해 줘.
랜딩 페이지의 앱 소개 부분은 [앱 소개]의 내용을 참고해서 작성해줘.

[스티치 파일]
스티치 파일은 stitch_design 밑에 있어. 컬러 배색은 DESIGN.md를 참고해,
소개하는 앱들에 대해서는 아이콘 이미지 파일을 사용해줘. 앱 이름과 같은 이름으로 파일을 저장했으니 확인할 수 있을거야.

[기능1. 앱 소개]
생활의 편의를 위해 만든 '아무거나' 앱들을 소개하는 내용이야. 제목과 개요, 그리고 링크가 들어가.
랜딩페이지에서 아이콘을 클릭하면 바로 새로운 페이지에서 해당 앱이 구동될거야.
'Simple Reader : 언제 어디서나 PDF 파일을 읽고, 책갈피, 번역 메모 등을 공유합니다. https://simple-reader-doohee2.vercel.app/
'Word Smart' : 영어, 일본어 한자, 한자 단어들을 공부하고, 학습 기록을 확인합니다. https://word-smart-doohee2.vercel.app/
'Simple Schedule' : 구글 캘린더와 연동해서 자주 쓰는 기능 위주로 편집한 캘린더 앱으로서, 노션 체크리스트 기능을 지원합니다. https://simple-schedule-doohee2.vercel.app/
'My Drive Finder' : 사용자의 구글 드라이브에서 Excel, CSV 파일의 내용을 검색하는 앱입니다. https://my-drive-finder-doohee2.vercel.app/
'Lens Dictionary' : 카메라 스캔을 지원하는 영한 사전앱입니다. 스타딕 파일을 지원합니다. https://lens-dict-doohee2.vercel.app/
'Subway Tracker' : 지하철 도착 정보를 조회하는 앱입니다. https://subway-tracker-doohee2.vercel.app/

[기능2. 개인정보처리방침]
마크다운 형태로 저장된 "privacy-policy.md" 파일을 읽어서 그대로 수록해줘.
추후에 수정 사항이 발생항 경우, 해당 파일을 수정하는 걸로 대신할 수 있게 해주면 좋겠어.

[기능3. 구글 로그인 본인 인증]
개인정보삭제를 요청시 구글 로그인을 통해서 구글 계정 확인을 해야해.
개인정보삭제 요청 버튼을 클릭하면, 구글 계정 로그인을 통해 이메일 확인을 하는 절차를 마련해줘.
추후에 연결된 supabase 에서 개인정보를 삭제하는 쿼리문에 대한 지시를 따로 할거야.
