# 개인정보처리방침 (Privacy Policy)

**시행일자: 2026년 10월 10일**  
**최종 수정일: 2026년 10월 10일**

본 서비스(이하 '서비스')는 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 및 구글 API 서비스 사용자 데이터 정책(Google API Services User Data Policy)을 엄격히 준수합니다. 본 방침은 당사가 운영 및 배포하는 웹 애플리케이션 제품군(**Simple Reader, My Drive Finder, Simple Schedule, Word Smart, Lens Dictionary, Subway Tracker** 등)에 공통으로 적용됩니다.

---

### 제1조 (수집하는 개인정보 항목 및 수집 방법)

서비스는 별도의 회원가입 절차 없이 구글 로그인(Google OAuth 2.0)을 통해 최소한의 식별 정보와 서비스 구동에 필수적인 API 권한만을 수집 및 이용합니다.

1. **기본 로그인 및 계정 식별 정보 (Google OAuth 공통)**
   * **수집 항목:** 구글 계정 이메일 주소(Email), 고유 계정 식별자(Google Sub ID), 프로필 이미지 주소.
   * **수집 방법:** Google OAuth 2.0 연동 및 세션 콜백.

2. **애플리케이션별 구글 API 접근 권한 (OAuth Scopes)**
   각 앱의 고유 기능을 수행하기 위해 필요한 최소한의 범위(Least Privilege)로 한정하여 권한을 요청합니다:
   * **Simple Reader (AI 기반 스마트 이북 리더기):**
     * **권한:** Google Drive API (`drive.readonly` - 구글 드라이브 읽기 전용 권한)
     * **목적:** 사용자가 지정한 '내 서재' 또는 구글 드라이브 내 PDF 파일 탐색, 바이너리 다운로드 및 브라우저 로컬 캐싱.
   * **My Drive Finder (구글 드라이브 파일 검색기):**
     * **권한:** Google Drive API (`drive.file` - 앱이 직접 생성하거나 선택한 파일에 대한 접근 권한)
     * **목적:** 사용자가 선택한 폴더 내 스프레드시트/CSV 메타데이터 동기화, 프록시/다이렉트 다운로드 및 파일 업로드.
   * **Simple Schedule (심플 스케줄러 & 루틴 PWA):**
     * **권한:** Google Calendar API (`calendar.events` - 구글 캘린더 일정 관리 권한)
     * **목적:** 사용자 캘린더 일정 목록 조회, 신규 일정 생성, 일정 수정/삭제 및 공휴일 캘린더 연동.
   * **Word Smart (영단어 학습 PWA):**
     * **권한:** Google Drive Picker 기반 단어장(CSV) 파일 선택 및 열람.

### 제2조 (개인정보의 처리 목적)

수집된 정보는 다음의 목적을 위해서만 처리되며, 마케팅, 타깃 광고, 제3자 프로파일링 등 다른 용도로 일절 사용되지 않습니다:

1. **사용자 식별 및 기기 간 동기화:** 구글 계정 식별자 기반으로 로컬 기기(IndexedDB / Dexie.js / localForage)와 클라우드 데이터베이스(Supabase) 간의 메모, 책갈피, 단어장 학습 이력, 캘린더 일정 동기화.
2. **서비스 프록시 기능 제공:** 사용자 요청에 따른 구글 드라이브 파일 중계 및 구글 캘린더 일정 실시간 API 프록시 처리.
3. **서드파티 연동 자격증명 보관 (Simple Schedule):** 이용자가 자발적으로 입력한 노션(Notion) 통합 토큰 및 데이터베이스 ID의 안전한 서버 측 격리 보관.

### 제3조 (개인정보의 보유 및 파기 절차)

원칙적으로 개인정보의 수집 및 이용 목적이 달성되면 지체 없이 해당 정보를 파기합니다.

1. **보유 기간**
   * **로그인 세션 토큰:** 세션 쿠키 수명은 최대 180일로 유지되며, 토큰 만료 또는 로그아웃 시 즉시 무효화됩니다.
   * **동기화 메타데이터 (Supabase):** 사용자가 서비스를 이용하는 동안 보관되며, 탈퇴 또는 삭제 요청 시 지체 없이 영구 삭제됩니다.

2. **논리적 삭제(Soft Delete) 및 30일 자동 영구 파기 정책**
   * 사용자가 메모, 책갈피, 단어장 기록, 캘린더 일정을 삭제할 경우 데이터베이스 내 `deleted_at` 타임스탬프가 기록되는 논리적 삭제 상태로 전환됩니다.
   * 논리적 삭제 후 **30일이 경과하면 백엔드 배치 스케줄러 및 동기화 루틴을 통해 로컬 스토리지와 서버(Supabase) 양쪽에서 복구 불가능하게 자동 영구 파기(Hard Delete)**됩니다.

3. **이용자 주도형 데이터 파기 및 계정 연결 해제 방법 (구글 검수 필수 요건)**
   이용자는 언제든지 자신의 개인정보와 저장 데이터를 직접 파기할 수 있는 완전한 통제권을 가집니다:
   * **데이터 삭제 버튼:** 각 애플리케이션의 **개인정보처리방침** 안내 버튼을 통해 **데이터 삭제** 웹 페이지로 연결되어, Supabase에 저장된 모든 데이터 레코드와 기기 로컬 캐시를 즉시 영구 삭제할 수 있습니다.
   * **본인 확인 절차:** 비인가자에 의한 악의적 데이터 훼손을 방지하기 위해, 데이터 초기화 실행 시 **구글 OAuth 재인증(로그인)**을 거쳐 소유자 본인임을 확인한 후 파기를 집행합니다.
   * **오프라인 캐시 소각:** 사용자가 PWA 앱을 삭젝하거나 웹 브라우저 데이터를 초기화할 경우, 서비스 워커 캐시 스토리지(Cache API)와 IndexedDB/LocalStorage에 잔류하는 오프라인 민감 캐시를 즉시 완전히 소각합니다.
   * **서면 요청 채널:** 앱 UI 접근이 불가능한 경우, 개인정보 관리 책임자 이메일(앱 내 지원 채널)로 구글 계정 정보를 기재하여 삭제를 요청하면 접수 즉시 영구 파기 처리됩니다.

### 제4조 (구글 사용자 데이터 정책 준수 및 제한적 사용 선언)

본 서비스는 **Google API Services User Data Policy**(제한적 사용 요건 포함)를 엄격히 준수합니다:

1. **인공지능(AI) 학습 활용 금지:** Google API(구글 드라이브, 구글 캘린더)를 통해 수집하거나 조회한 사용자 데이터를 외부 LLM(대형 언어 모델)의 일반 학습 데이터로 일절 사용하지 않습니다. Simple Reader에서 제공하는 제미나이(Gemini) 번역 및 요약 기능은 사용자가 브라우저 상에서 직접 선택·드래그한 텍스트에 한해 단발성 API 요청으로만 처리되며, 모델 학습용 데이터셋으로 저장되지 않습니다.
2. **데이터 판매 및 불법 전송 금지:** 사용자 데이터를 타사에 판매하거나, 서비스 본래의 기능 제공과 무관한 제3자 플랫폼으로 전송하지 않습니다.
3. **인간 개입 금지:** 서비스 운영 인력은 사용자의 명시적인 사전 동의(오류 분석 요청 등)가 있거나 법적 의무가 발생하는 경우를 제외하고, 사용자의 구글 드라이브 문서 및 캘린더 일정 내용에 직접 접근하거나 열람하지 않습니다.

### 제6조 (개인정보의 기술적·관리적 보호 조치)

서비스는 다음과 같은 엔터프라이즈급 4단계 보안 체계를 구축하여 개인정보를 보호하고 있습니다:

1. **식별자 익명화 및 단방향 해싱 (선택적 적용):** 서버에 이메일 주소를 평문으로 보관하지 않고, 무작위 솔트(Salt)와 결합한 SHA-256 단방향 암호화 해시 처리를 거쳐 복호화가 불가능한 고유 식별자로 격리 저장할 수 있습니다.
2. **토큰 및 비밀 자격증명 격리 (Zero-Leak):** Google OAuth 토큰 및 세션은 브라우저 스크립트가 접근할 수 없는 `HttpOnly, Secure` 암호화 쿠키로 보호되며, 백엔드 기밀 키에는 클라이언트 공개 접두사를 일절 배제하여 클라이언트 유출을 원천 봉쇄합니다.
3. **서버 측 소유권 인가 및 스키마 검증:** 모든 프록시 엔드포인트는 클라이언트 파라미터를 신뢰하지 않고 서버 측 세션 기반으로 인가를 통제하며, 스키마 검증을 통해 입력값을 검증하고 상세 오류 스택은 브라우저에 반환하지 않도록 위생화(Sanitization) 처리합니다.
4. **전역 HTTP 보안 헤더 장착:** 모든 서비스 라우트에 HSTS(HTTPS 강제 통신), X-Frame-Options(클릭재킹 방어), CSP(Content Security Policy), Permissions-Policy를 의무 적용합니다.
