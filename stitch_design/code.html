개인정보처리방침

앱들은 편리하고 일관된 사용자 환경을 위해 구글 OAuth(Google OAuth 2.0)를 지원하며, 구글 개발자 정책에 따른 개인정보처리방침을 투명하고 정직하게 공개합니다.

자주 묻는 질문

이용자분들이 가장 궁금해하시는 점들을 투명하게 안내해 드립니다.

현재 기능으로 안정적으로 제공되나, 바이브 코딩 및 인디 프로젝트 특성상 추후 기능 추가나 지속적인 대규모 업데이트 개선을 공식 약속할 수는 없습니다. 하지만 중요한 버그 수정과 API 변경에 대응하는 유지보수는 지속적으로 모니터링하여 대응하고 있습니다.
구글 계정 연동은 안전한 Google 공식 OAuth 2.0 인증을 통해 사용자 구분을 위해서만 사용되며, 주민등록번호, 비밀번호 등 민감한 개인정보는 일체 수집하거나 서버에 저장하지 않습니다. 자세한 사항은 상단의 개인정보처리방침을 참고해 주세요.
'My Drive Finder' 앱은 사용자가 지정한 파일의 검색 조회 목적으로만 최소한의 읽기 권한을 클라이언트 브라우저 세션 내에서 요청하며, 서버로 파일 원본이나 열람 내용을 별도로 전송하거나 저장하지 않습니다.
